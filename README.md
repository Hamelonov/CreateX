# ⚛️ Createx — React Web Application

Современное веб-приложение, разработанное на базе библиотеки **React**. Проект создан в рамках глубокого изучения экосистемы React, принципов компонентного подхода, управления глобальным состоянием и интеграции современных инструментов фронтенд-разработки.

---

## 🛠️ Стек технологий и архитектура

В проекте реализован современный стек, востребованный в коммерческой разработке:

*   **Core:** React (Функциональные компоненты, Hooks)
*   **Стилизация:** SCSS (Модульные стили, переменные, миксины)
*   **Методология верстки:** БЭМ (для изоляции стилей компонентов)
*   **Управление данными:** Работа с асинхронными запросами (Fetch/Axios), MOCK-овые данные
*   **Инструменты сборки:** Vite, менеджер пакетов npm
*   **Контроль качества:** Компонентный подход, оптимизация рендеринга, чистая архитектура

---

## 🔬 Что было освоено и реализовано в проекте

*   **Компонентная архитектура:** Разделение интерфейса на независимые, переиспользуемые UI-компоненты.
*   **Управление состоянием (State Management):** Глубокая работа с хуками (`useState`, `useEffect`, `useContext`, `useRef`), организация передачи данных между компонентами без prop-drilling.
*   **Жизненный цикл компонентов:** Оптимизация побочных эффектов (Side Effects) при монтировании, обновлении и размонтировании элементов.
*   **Адаптивность и Интерактивность:** Полная адаптация интерфейса под любые разрешения экранов, обработка комплексных пользовательских событий и валидация форм.
*   **Маршрутизация (если использовалась):** Настройка клиентского роутинга для создания SPA (Single Page Application).
